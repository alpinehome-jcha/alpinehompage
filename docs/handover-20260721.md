## 4. 🎨 UI/UX 및 랜딩 페이지 렌더링 최적화

### 4.1 제품 라인업 이미지 비율 정상화

### 4.2 히어로 슬라이더 블라인드 효과 HTML `<img>` 레이어 재설계
- [`index.html`](file:///c:/Antigravity/alpine-homepage/index.html): CSS `background-image` 연산 방식에서 발생하던 픽셀 위치 오차 및 hairline 틈새를 해결하기 위해 **실제 HTML `<img>` 레이어 샌드위치 구조**로 리팩토링.
