무쏘EV 알파인 오디오 옵션 차량_저음보강 알파인 서브우퍼 장착_PWE-M770

2026-02-09 | Posted by Admin
무쏘 EV 블랙엣지 차량에 기본 장착된 알파인 오디오는 OEM 4채널 사운드 시스템을 비약적으로 향상 시킨 프리미엄 사운드입니다.
아쉬운점은 4채널 특성상 서브우퍼가 부재한점입니다.

알파인 서브우퍼 PWE-M770은 300W급 모노앰프가 내장된 7" 고성능 제품으로 공간이 협소한 KGM 무쏘EV 차량에 알맞은 제품입니다.

Subwoofer Type : 7 x 7" Powered Subwoofer Box
Frequency response : 10 Hz - 150 Hz
Power handling : 300 Watts peak power
Sensitivity : 90dB


https://www.alpine-korea.co.kr/pages/products/pwe-m770.html
무쏘 EV 오너들이 알파인 서브우포 PWE-M770을 선택하는이유?
1. 순정 인테리어를 해치지 않는 디자인으로, 트렁크 공간 무손상 시공 탈부착이 간편하며, 순정 감성을 그대로 유지합니다.
2. 강력하면서도 균형잡힌 저역 , 알파인 서브우퍼는 도어 스피커와의 밸런스를 고려한 트닝으로 묵직하지만 퍼지지 않는 저음, 풍부하면서도 정제된 저역을 구현합니다.
3. KGM의 알파인 오디오와의 호환성, RCA단자로 연결되며, 알파인 오디오의 DSP AMP에는 알파인 서브우퍼 PWE-M770을 튜닝할 수 있도록 구성되어 있습니다.
4. 컨트롤러 장착, 베이스 조절 컴트롤러를 장착해서 주행 중에소 음악에 따라 손쉽게 조절할 수 있습니다.
KGM 알파인 오디오는 사운드 튜닝이 가능한 상품이므로, DSP와 스피커를 다른 상품으로 변경 할 필요가 없습니다.
KGM AS 이슈가 발생 할 수 있으니 알파인 DSP와 알파인 스피커는 다른 상품으로 변경하지 마실 것을 권장합니다.
